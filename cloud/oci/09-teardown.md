# 09. 리소스 종료·삭제 및 비용 종료 점검

- **상태:** 미진행

## 종료 전

- [ ] 필요한 코드·실습 결과·설정(비밀정보 제외) 백업
- [ ] VM 중지와 **종료(Terminate)**가 다른 것임을 확인
- [ ] 부팅/블록 볼륨 보존 여부 선택
- [ ] 공인 IP·로드밸런서·NAT Gateway 등 추가 유료 리소스 확인

## 종료 시

- [ ] 불필요한 Compute 종료
- [ ] 잔여 Boot/Block Volume 삭제 여부 확인
- [ ] 스냅샷·백업·Object Storage 및 기타 유료 자원 확인
- [ ] 비용 관련 부가 서비스/리소스 점검

## 종료 후

- [ ] OCI 리소스 목록에서 잔여 항목 확인
- [ ] 지연 반영될 수 있는 청구 내역을 후속 확인
- [ ] 해당 실습의 최종 비용 기록

> 리소스 종료만으로 계정의 모든 청구가 즉시 0이 된다고 가정하지 않습니다. 무료 체험 종료·유료 전환 여부도 별도로 확인합니다.
