# 01. 비용 및 크레딧 보호 체크리스트

- **상태:** 미진행

## 생성 전 (필수)

- [ ] 계정의 실제 무료 체험 상태와 만료일 확인
- [ ] 현재 크레딧 잔액과 적용 대상 서비스 확인
- [ ] 사용할 리전의 Compute / Boot Volume / Network 관련 요금 검토
- [ ] Budget 및 경고 알림 구성, 실제 수신 이메일 확인
- [ ] 예상 자원·가동 시간을 기준으로 최대 노출액 계산
- [ ] 사용하지 않을 리소스를 삭제할 종료 계획 작성

## 유의 사항

**Budget Alert는 보통 지출을 자동 차단하지 않습니다.** 크레딧이 있어도 서비스·용량·계정 유형에 따라 별도 청구가 가능한지 확인해야 합니다.

**VM 중지와 비용 0원은 같은 뜻이 아닙니다.** 부팅 볼륨 등 유지 자원이 청구될 수 있으므로 실제 과금 항목을 확인합니다.

|---|---|---|---|---|---|---|
| YYYY-MM-DD | | | | | | |

> 단가는 계속 바뀔 수 있으므로 여기에는 실습 당시 OCI 요금 화면/문서와 확인일을 함께 기록합니다.
