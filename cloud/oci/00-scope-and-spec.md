# 00. 실습 목표 및 Compute 사양 확정

- **상태:** 미확정 / 실습 전 확인 필요
- **목표:** OCI 무료 체험 크레딧 범위에서 AI 플랫폼 환경 구축·학습

## 목표 워크로드

- [ ] Ubuntu 접속·관리
- [ ] Docker 및 컨테이너 실습
- [ ] Kubernetes 기본 실습
- [ ] Kubeflow/KFP 설치 가능성 검토
- [ ] 자원 증설·축소 실험

## 결정 전 확인

- [ ] CPU 아키텍처와 컨테이너 이미지 호환성
- [ ] 무료 제공 범위·체험 크레딧 조건
- [ ] 중지 시에도 비용이 남는 리소스(특히 스토리지) 확인
- [ ] 사양 변경 시 재부팅/중지 필요 여부 및 볼륨 영향 확인
- [ ] 종료·삭제 뒤 잔여 리소스 처리 계획

> OCPU·vCPU는 클라우드 공급자와 Shape에 따라 환산 기준이 다릅니다. 숫자 비교만으로 동일 성능이라고 판단하지 않습니다.
