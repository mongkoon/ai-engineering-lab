# AI Platform Engineering 학습 로드맵

## 단계별 연결

| 단계 | 지식 영역 | 산출물 |
|---|---|---|
| 1 | AI 플랫폼 개념 및 XOps 기초 | 아키텍처 개요 |
| 2 | Linux / Docker | 컨테이너 실행 기록 |
| 3 | Kubernetes | Pod, Deployment, Service 매니페스트 및 검증 |
| 4 | 클라우드(OCI 우선) | VM, 네트워크, 비용 관리 기록 |
| 5 | Kubeflow / MLOps | KFP 전처리→학습→평가 실험 |
| 6 | LLMOps / RAG | 검색 파이프라인 및 검색 품질 평가 |
| 7 | 운영 자동화 | IaC, 재현성, 모니터링, 보안 체크리스트 |

> 강의 실습 주제의 학습 흐름을 참고하되, 실제로 완료한 내용은 별도로 검증해서 기록합니다.
