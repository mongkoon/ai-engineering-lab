# 문서 작성 규칙

각 실습은 다음 정보를 가능한 한 포함합니다.

| 항목 | 설명 |
|---|---|
| 날짜 | 수행일(현지 시간대 명시) |
| 환경 | OS, 아키텍처, 클라우드 리전, 도구 버전 |
| 사전 조건 | 필요한 계정·리소스·권한 |
| 목표 | 기대 결과와 성공 조건 |
| 실행 | 실제 실행한 명령·설정 |
| 검증 | 출력·스크린샷·테스트 결과 |
| 비용 | 생성/유지/종료에 따른 과금 가능성 |
| 보안 | 노출 포트, IAM, 자격 증명 |
| 정리 | 중지·삭제·잔여 리소스 확인 |
| 회고 | 실패·트레이드오프·재현 가능한 교훈 |

`[ ]`는 미완료, `[x]`는 검증 완료에만 사용합니다. 계획과 실제 결과를 혼동하지 않습니다.
