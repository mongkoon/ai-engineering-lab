# Kubeflow / KFP

예정 실습:

1. KFP SDK 버전과 플랫폼 호환성 확인
2. `@dsl.component`, `@dsl.pipeline`로 파이프라인 구성
3. Dataset / Model / Metrics 전달과 실험 비교
4. Run 결과 및 파라미터·메트릭·비용 관찰

원본 강의자료를 그대로 재배포하지 않고 직접 실습한 코드·결과·회고를 기록합니다.

> 구분: 이 폴더는 Kubeflow 플랫폼 설치·구성과 운영을 기록합니다. 실제 KFP 학습 코드와 실행 비교는 [`mlops/training-pipelines/`](../../mlops/training-pipelines/)에서 기록합니다.
